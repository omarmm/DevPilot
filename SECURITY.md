# Security Policy

DevPilot is an early preview. Please keep the following points in mind:

- Never publish private SSH keys, access tokens, passwords, or unredacted personal configuration in issues or pull requests.
- Use a secure Git credential manager for HTTPS authentication. DevPilot does not currently provide per-account HTTPS credential isolation.
- Review managed configuration changes and retain secure backups of important credentials.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for this repository when it is enabled, or contact the maintainer privately through the GitHub profile:

https://github.com/omarmm
